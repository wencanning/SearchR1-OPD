# 从问题诊断到论文主图：证据更新不足的实验方案

日期：2026-09-15。当前已完成真实数据绘图和引言重写；下面的大样本、额外教师推理与学生训练均为待执行方案，不是已有结果。本次只做 CPU 数据分析与绘图。

## 1. 要证明的三个命题

P1（现象）：在自然生成的学生状态上，存在“直接访问充分证据使正确候选相对支持增加，但完整教师仍偏错”的状态。P1 不等于“找到证据后学生答错”，后者还可能来自教师已正确、学生未学会或采样随机性。

P2（目标干预）：在上述状态中，ER 的目标调整能带来超出普通锐化的、完整答案层面的改进。仅验证 ER logits 的线性恒等式不算独立效果证据。

P3（学习收益）：目标改善转化为新学生在相同预算下的实际纠错，并保持原本正确的能力。教师候选分数或推理时使用 ER 解码都不能单独证明 P3。

当前证据：P1 有局部实例；P2 有事后别名及答案正文计分下的实例，也有反例；两个固定错误案例的续写无新增纠错；P3 未检验。不能把一张美观的图作为补足这三层证据的替代。

## 2. 借鉴 SOD 的方式

核对版本：[SOD v3, Figure 1, PDF 第 2 页](https://arxiv.org/pdf/2605.07725v3)。其图注称 (a) 对 800 条轨迹分析逐步分歧，(b) 分析教师熵均值变化和波动，(c) 展示基准表现。值得借鉴的是从可观测失效到监督变化再到效果的证据顺序，而不是雷达图形式。我们的假设没有“随步数单调加重”的证据，不应照抄上升曲线。

当前图采用两个面板，全部数值来自上轮冻结 CPU 产物：

- (a) 六条技术合格且证据充分的学生错误，同一前缀下首个分歧 token 的 hidden/observed 对数赔率散点；三条历史复核通过为实心，三条仅 FP32 内部补充为空心。所有六条都画，不筛掉 E002 反例。
- (b) E017 常用名的完整候选分数，明确标为事后别名敏感性；图注同时给出原定完整姓名下不翻转的结果。

这张图可作为明确标注的 motivating pilot / case study。建议正式投稿主图在完成下述新样本验证后替换为更强的整体证据，不能直接拿 n=6 或事后案例宣称普遍优势。

## 3. 精确定义，避免换指标

局部机制量：在两候选首个分歧位置的同一前缀上，定义

$$m_v=\log p_v(c\mid h)-\log p_v(w\mid h),\quad v\in\{\mathrm{hid},\mathrm{obs}\},\quad\Delta=m_{\mathrm{obs}}-m_{\mathrm{hid}}.$$

目标状态为 $m_{\mathrm{hid}}<m_{\mathrm{obs}}<0$，也就是图中对角线上方且横向零线下方。这里的“更新”是两个固定可见性视图的差，不是不同训练步或时间上的因果更新。数值边界应另报 $\epsilon=0.05,0.1$ nat 的敏感性，不用接近零的浮点噪声计为翻转。

同状态 ER 有 $m_{\mathrm{ER}}=m_{\mathrm{obs}}+\alpha\Delta$。这解释了当 $\Delta>0$ 时何种 alpha 可越过零；它不证明完整答案或生成会被纠正。不同候选后续前缀及归一化项不同，不能把这个恒等式套用到完整序列分数。

完整答案量：在人工审查但看不到方法分数时，固定合法别名集合 $\mathcal A_c$ 和错误答案类别及别名集合 $\mathcal A_{w_j}$。对含明确终止符的完整字符串计算有限集合概率质量：

$$M_v=\log\sum_{a\in\mathcal A_c}P_v(a\mid h)-\max_j\log\sum_{b\in\mathcal A_{w_j}}P_v(b\mid h).$$

所有方法使用完全相同的集合；字符串去重、终止格式固定、同一答案集合内不得混入语义不同的对象。概率质量不是“最佳别名分数”。同时报告每个别名、正文/含关闭格式、总分/均分的敏感性，不能事后只取最有利措辞。有限候选集依然不等于开放词表正确率，必须另做自由生成。

错误候选池包括学生原错误答案、普通教师与 hidden 教师的错误续写，先合并、语义归类并冻结，之后才对 ER 打分。不能只让正确答案和一个明显低质的学生答案竞争。ER 新生成但池中没有的错误单列报告，不回改主候选集。

## 4. 实验 A：先确认自然发生率

根据用户确认，训练数据仅为 HotpotQA。建议固定 200 个未复核的 HotpotQA 诊断问题，在普通 OPD 参考运行的早/中/晚三个快照上各生成一条自然轨迹，共最多 600 个状态；同一批问题在三个阶段重复使用以控制题目组成。阶段事先按计划更新数 20%/50%/80% 指定，不按验证分数或崩溃点选。保持同一冻结教师，不混合不同方法充当阶段差异。若某阶段快照不可得，先记录设计修订再打分，不以方便案例补足。

不能先筛 EM=0 或 ER 可纠正案例。先对所有抽到的状态做语义正确性、证据充分性、格式合法性审查。EM 别名错误、参考歧义、证据缺失分别保留。目标状态的主分母为全部“证据充分且技术合格”的自然状态，包含学生正确状态；再报告其中普通教师偏错的条件比例。另报从 200 个问题、最多 600 个状态到各阶段有效状态的完整流程和排除数量。

建议两名审查者分别标注问题、证据和答案，隐藏方法、教师分数与 ER 结果；报告一致性和分歧处理。若这一阶段发现目标状态很少，应报告宽置信区间并缩小主张，不能不断补抽直到积攒足够正例。现在只有一个教师；若要宣称一般机制，应在另一个教师上复核同一固定面板。

以问题为统计单位，分训练阶段报告计数和 Wilson 区间；跨 checkpoint 或多候选涉及同题时，用按问题聚类的 bootstrap，不能把 token 当独立样本。正式 A 图优先画完整答案 $M_{\mathrm{hid}}$ 对 $M_{\mathrm{obs}}$ 的散点和目标区域比例，局部 m 图放配套诊断。当前图 (a) 只有局部 m，不混为同一指标。

## 5. 实验 B：在相同状态上区分残差方向与普通锐化

固定教师、精度、tokenizer 有效词表、原生答案边界、候选和生成随机种子。先通过全答案逐 token 复现、零 mask 和同前缀检查；未通过者不混入主分析。

比较条件：普通教师、ER alpha=1、固定温度普通教师（独立开发集选定）、无标签逐位置熵匹配普通教师，以及随机等长度 mask 残差对照。alpha=.5/1.5 只作敏感性，不能替换主强度。随机 mask 控制选择不应根据正确性，保留多个预先固定随机种子。

同时报告目标状态中 $M$ 的成对变化、候选翻转率，以及全部充分证据状态中的净收益（新增正确−新增错误）。如果只在目标子集中报告“成功率”，会遗漏 E002 这类方向有害的状态。正的温度缩放保持单位置 token 排序，局部 ER 翻转超越温度是代数上预期的；完整答案、开放生成与学生学习才是更强的独立验证。

自由生成从同一固定状态开始，不提供正确答案文本，不只选最短或最好的几个案例。长度上限在分数揭盲前按任务正常答案长度固定，所有条件相同；未终止计为未完成。采用可审计的答案归一化加盲审语义判断。配对比较正确性与置信区间。当前 E003 表明即便正确候选超过学生原答案，教师仍可能生成第三个错误答案。

## 6. 实验 C：补上“为什么”及方法边界

当前 observed/hidden 只能说明响应方向，不足以确定错误偏好来自学生历史、模型先验还是文档混淆。做 2×2 配对干预：证据访问开放/屏蔽 × 最后一次检索后的学生解释访问开放/屏蔽。保持 token 序列和位置一致，协议标签保留，仅在明确识别的正文注意力 key 上操作，计算四个条件的 m、M 和完整生成。

如果屏蔽学生解释后错误偏好减弱，支持该注意力路径在这批状态上的作用；如果没有变化，不写“学生历史压制证据”。补充等长度随机历史屏蔽控制，以区分特定错误解释与任意上下文破坏。不能将屏蔽差分解读为纯参数先验，模型中仍可能存在其他间接信息路径。

再以正确证据、无关证据、与事实冲突的证据作为单独标注的受控压力测试，保持工具格式和近似长度，报告 ER 是否放大错误残差。人造压力测试用于测试边界，不能用于估计自然发生率，也不能混入主自然样本来夸大效果。

## 7. 实验 D：从教师目标到学生收益

学生收益图统一在未参与训练的 HotpotQA 留出问题上评价。先在同一学生快照的隔离副本上做小规模配对更新：普通 OPD、熵匹配 OPD、ER-OPD、SOD 加权、SOD 加权+ER 目标。固定采样数据和更新预算，至少三个更新随机种子；用新的续写/留出问题评价，不用被优化的候选分数当泛化收益。

SOD 加权与 ER 可组合。对于同一固定状态，SOD 不重排原教师目标，这只是局部目标层面的区别；它通过轨迹变化和结果奖励仍可能纠错。因此，与完整方法比较时必须使用 SOD 的完整可比训练配置，不能拿本地无 GRPO、单 rollout 消融作论文最终基线。

完整训练同时报告按相同 rollout 数/更新数，以及按总教师 token 计算量或墙钟预算的两种比较。ER 需要额外教师前向，不能把等步数比较称为等计算预算。控制正确状态的退化、最终 EM/F1、搜索调用次数与训练稳定性。冻结方法超参数的开发集与最终评估集分开。

正式 Figure 1 建议最终为：(a) 自然样本上的完整答案更新差距；(b) 固定状态上目标干预的完整生成净纠错与置信区间；(c) 留出问题上的学生纠错增益与正确率保持。第三面板没有可靠数据时不画，不使用示意数值填充。

## 绘图计划修订：按学生训练步数追踪

用户进一步要求参照 SOD 展示随 training step 的变化。第一幅主图因此由三阶段分组改为固定间隔的检查点折线；同一冻结教师在每个学生检查点对应的自然轨迹上评分。固定诊断问题集，实际检查点在新评分前按训练计划指定；例如 7 个检查点 × 200 个问题为最多 1400 个状态。上述三阶段抽样描述由本修订替代，其他语义审查、精度排除、配对与按问题聚类统计原则不变。

最新草图中的 0–120 步及所有比例仍为合成布局值，不代表实际完成的检查点。不能以草图走势断言训练导致问题加重；真实结果可以上升、持平或下降。
