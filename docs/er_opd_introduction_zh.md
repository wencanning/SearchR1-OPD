# 引言

搜索型智能体的价值不在于能够调用搜索工具，而在于能够依据新获得的证据改变后续决策。与一次性检索后生成答案的传统检索增强生成不同，Agentic RAG 将信息获取建模为一个多轮决策过程：模型需要判断何时搜索、生成什么查询、如何理解返回的文档，以及何时停止搜索并给出答案。这种范式能够突破模型参数知识的边界，但也给训练带来了更困难的信用分配问题。最终答案奖励只能说明整条轨迹是否成功，却难以指出某次检索获得的证据如何影响了之后的推理、查询和回答。对于参数量较小的搜索智能体，这种稀疏而延迟的监督尤其容易导致训练不稳定、无效搜索和对检索内容利用不足。

现有研究主要从强化学习算法、搜索过程监督和检索模块三个方向缓解上述问题。[Search-R1](https://arxiv.org/abs/2503.09516) 通过端到端强化学习训练模型交替执行推理与搜索，奠定了当前搜索智能体的基本范式；[InForage](https://arxiv.org/abs/2505.09316) 为中间检索行为设计细粒度奖励，[DGPO](https://aclanthology.org/2026.acl-long.1751/) 和 [SAPO](https://arxiv.org/abs/2603.10069) 则分别从选择性教师指导和稳定策略优化的角度改善小模型训练。这些方法提升了搜索策略的可学习性，但大多仍依赖结果奖励或人为设计的过程信号。如何直接从检索观察本身提取稠密、与当前策略状态匹配的训练信号，仍然缺少系统研究。

在学生自身访问的状态上提供教师反馈的在策略蒸馏，为这一问题提供了另一种思路。与模仿教师生成轨迹的离线蒸馏不同，在策略蒸馏首先由学生生成动作，再让更强的教师对这些动作进行评价，从而减少教师轨迹与学生状态分布之间的错位。近期工作已将特权上下文、逐步教师加权和技能条件分支引入推理与多轮智能体训练，例如 [OPCD](https://arxiv.org/abs/2602.12275)、[SOD](https://arxiv.org/abs/2605.07725) 和 [SEED](https://arxiv.org/abs/2607.14777)。然而，这些方法通常将教师在给定上下文下的预测分布视为一个整体目标，或者利用上下文差异筛选、门控教师信号。它们没有显式回答一个对 Agentic RAG 至关重要的问题：**教师对当前动作的偏好，究竟有多少是由刚刚检索到的证据引起的？**

这一缺口使普通在策略蒸馏面临一个检索特有的混淆。教师在完整轨迹中可能高度支持某个 token，但这种支持既可能来自检索文档，也可能来自教师的参数知识、问题中的表面线索、回答格式偏好或此前的推理前缀。因此，直接蒸馏完整上下文下的教师分布，只能告诉学生“教师更偏好什么”，却无法区分“教师原本就偏好什么”与“检索证据使教师更加偏好什么”。近期的 [SA-OPD](https://arxiv.org/abs/2608.03632) 已表明，输入无关的先验和模板偏好可能形成误导性的教师信号，并通过移除整个输入来识别和过滤这类 token。对于搜索智能体，我们关注一个更局部的问题：在问题、动作历史、协议结构和位置完全不变时，仅移除检索内容会怎样改变教师的预测？这种变化能够直接刻画检索观察对当前决策的增量支持。

基于这一观察，我们提出**证据残差在策略蒸馏**（Evidence-Residual On-Policy Distillation，ER-OPD）。对于每条学生生成的搜索轨迹，我们使用冻结教师进行两次相互独立的前向计算。在证据可见视图中，教师能够访问完整检索结果；在证据隐藏视图中，我们只阻断检索内容作为注意力键和值被后续 token 访问，同时保留原始 token 序列、位置编码、搜索协议标签和学生动作前缀。设两个视图产生的教师 logits 分别为 $$z_t^{\mathrm{obs}}$$ 和 $$z_t^{\mathrm{hid}}$$，ER-OPD 构造如下目标分布：

$$
q_t^{\mathrm{ER}}
=
\operatorname{softmax}\!\left(
z_t^{\mathrm{obs}}
+ \alpha\bigl(z_t^{\mathrm{obs}}-z_t^{\mathrm{hid}}\bigr)
\right).
$$

其中，$$z_t^{\mathrm{obs}}-z_t^{\mathrm{hid}}$$ 表示证据可见性引起的教师 logit 残差。该目标也可以解释为使用证据似然比重新加权完整上下文下的教师分布：

$$
q_t^{\mathrm{ER}}(v)
\propto
p_t^{\mathrm{obs}}(v)
\left(
\frac{p_t^{\mathrm{obs}}(v)}{p_t^{\mathrm{hid}}(v)}
\right)^{\alpha}.
$$

因此，看到检索证据后相对概率上升的 token 会得到更强监督，而在隐藏证据时已经具有较高概率的通用偏好不会被同等强化。我们进一步将该目标转化为学生采样 token 上的反向 KL 优势，并与基于最终答案奖励的 GRPO 优势联合使用。检索结果仍被视为环境观察，不参与策略损失；ER-OPD 只更新模型自己生成的推理、搜索动作和最终答案。

我们在 **[N 个问答数据集]**、**[M 种模型规模]** 上评估 ER-OPD。与仅使用结果奖励的 Search-R1/GRPO 相比，ER-OPD 将平均 **[EM/F1]** 提升 **[X.X]** 个百分点；与普通 OPD 相比提升 **[Y.Y]** 个百分点，并在 **[DGPO/SOD/当前最强可复现基线]** 下保持优势。进一步分析表明，ER-OPD 的收益主要出现在检索结果包含答案支撑证据的轨迹上。温度缩放和目标熵匹配实验排除了简单 logit sharpening 的解释，而随机遮蔽、证据打乱和无关文档实验揭示了该方法对检索质量的适用边界。以上结果说明，在学生自身访问的状态上显式建模教师的证据诱导偏好变化，可以为搜索智能体提供比完整教师分布更有针对性的稠密监督。

本文的主要贡献如下：

1. 我们指出并量化了普通在策略蒸馏在 Agentic RAG 中的一个检索特有局限：完整教师分布混合了检索证据带来的偏好与教师原有的、证据无关的偏好，因而无法显式为检索观察分配 token 级信用。
2. 我们提出 ER-OPD。该方法在同一条学生搜索轨迹上构造证据可见与证据隐藏的配对教师视图，并利用教师 logit 残差形成证据增强的全词表蒸馏目标。
3. 我们通过主结果、目标熵匹配、遮蔽干预和检索质量分层实验，验证 ER-OPD 的有效性，并区分证据残差监督与普通教师锐化、额外教师计算等替代解释。
