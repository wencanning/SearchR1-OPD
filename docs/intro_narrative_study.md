# ER-OPD 引言叙事调研笔记

本文档只总结代表性论文的 Introduction 如何建立问题，不替代正式 Related Work。

| 论文 | 开篇抓手 | 核心失配 | 方法转折 | 对 ER-OPD 的启示 |
|---|---|---|---|---|
| [Search-R1](https://arxiv.org/abs/2503.09516) | 大模型需要通过外部搜索获取知识 | 搜索工具、交错推理和 RL 难以稳定统一 | 将搜索建模为可端到端优化的多轮策略 | 先交代搜索训练范式，再落到一个具体训练缺口 |
| [DGPO](https://aclanthology.org/2026.acl-long.1751/) | 小模型能否像大模型一样进行智能搜索 | 小模型初始搜索能力不足，纯 RL 和直接 KD 均受限 | 冷启动蒸馏与选择性教师指导 | 方法必须直接对应小模型在搜索场景中的瓶颈 |
| [OPCD](https://arxiv.org/abs/2602.12275) | 上下文能临时赋予模型知识，但效果会随上下文消失 | 离线前向 KL 存在状态分布错位和 mode covering | 将上下文蒸馏改写为 on-policy 训练 | 可以从一个清晰的反事实问题引出配对上下文视图 |
| [SOD](https://arxiv.org/abs/2605.07725) | OPD 为小模型提供稠密监督 | 工具调用造成状态突变，错误工具反馈使教师监督失真 | 根据逐步分歧选择性加权 | 最有效的叙事是“成熟范式在目标场景中的特有失配” |
| [SEED](https://arxiv.org/abs/2607.14777) | 长程智能体只有结果奖励，缺少中间步骤监督 | 轨迹包含事后信息，但通常没有转化为参数监督 | 对普通视图和技能视图重新评分 | 上下文差分可形成 token 级信号，但 ER-OPD 必须强调检索观察的内生性 |
| [SA-OPD](https://arxiv.org/abs/2608.03632) | 选择性 OPD 默认教师信号有充分输入依据 | 教师可能依赖参数先验或模板，而常用置信度指标无法发现 | 用 prompt-removal contrast 估计输入 groundedness | 不应把 ER-OPD 泛化为通用 groundedness；应限定为检索观察的信用分配 |
| [SAPO](https://arxiv.org/abs/2603.10069) | 搜索 RL 已有效，但训练仍可能突然崩溃 | importance-ratio 漂移引发过度裁剪和奖励下降 | 用一个直接的条件正则项修复 | 引言应给出可测量的现象，并让方法保持单一、直接 |

## 共同叙事结构

这些论文的强引言大多遵循同一条路径：先承认一个已经成功的训练范式，再说明它进入目标场景后出现的结构性失配，随后用一个可观察的问题或反事实将失配具体化，最后提出与该失配一一对应的简单机制。它们通常不会同时讲多个平行动机。

## ER-OPD 的主线

ER-OPD 最有辨识度的冲突不是“教师原本偏好什么”，也不是泛泛地说“现有方法没有使用检索信息”，而是搜索轨迹中的优化不对称：检索正文能够改变后续策略，却因不是策略生成内容而没有直接的 token 学习目标，其作用只能通过后续生成和任务结果间接进入优化。普通 OPD 虽然让教师读取证据，却没有单独利用证据可见性对应的预测变化。

因此，引言的核心问题应写成：如何让搜索智能体直接从自己获得的证据对后续决策产生的影响中学习？ER-OPD 的回答是，在固定学生轨迹的条件下对比证据可见和证据隐藏的教师预测，将该差异转化为 token 级 on-policy 监督。
