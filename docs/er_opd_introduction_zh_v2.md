# 引言

每次检索都会向搜索智能体返回一段新的环境观察，但训练算法通常只在轨迹结束时告诉模型答案是否正确。在 Agentic Search/RAG 中，模型需要交替执行推理、查询生成、文档阅读和答案生成，并根据已经获得的信息决定下一步行动。与静态 RAG 相比，这种交互式信息获取方式能够处理更复杂的知识需求；与此同时，一次检索的价值往往要经过多轮推理后才会体现在最终答案中。终局奖励因而很难回答一个关键的信用分配问题：某段中间检索信息应当如何影响模型随后生成的推理、查询和答案 token？对于能力有限的小型搜索智能体，这一监督缺口容易表现为搜索行为不稳定、检索结果利用不足，以及反复搜索却不能据此修正答案。

现有搜索智能体训练主要通过结果强化学习、过程奖励和教师指导缓解这一问题。[Search-R1](https://arxiv.org/abs/2503.09516) 使用最终答案奖励端到端训练多轮搜索策略；[InForage](https://arxiv.org/abs/2505.09316) 等方法进一步评价中间检索行为，以改善搜索过程的信用分配；[DGPO](https://aclanthology.org/2026.acl-long.1751/) 和 [SAPO](https://arxiv.org/abs/2603.10069) 则分别从选择性教师指导和策略优化稳定性的角度提升小模型搜索能力。这些方法已经能够利用检索结果：模型将检索文本作为后续生成的上下文，部分方法也会为检索轮次提供额外奖励。然而，将检索结果作为输入并不等于将其中的信息充分转化为监督。最终奖励只能评价整条轨迹，检索过程奖励通常将一次搜索压缩为标量分数，两者都难以直接说明获得该检索结果后，模型的后续 token 应当如何变化。

在策略蒸馏为后续 token 提供了更细粒度的监督。它首先让学生策略生成搜索轨迹，再由更强的教师在学生实际访问的状态上评价其动作，从而避免单纯模仿教师轨迹所造成的状态分布错位。近期的 [OPCD](https://arxiv.org/abs/2602.12275)、[SOD](https://arxiv.org/abs/2605.07725) 和 [SEED](https://arxiv.org/abs/2607.14777) 分别从特权上下文、逐步重加权和技能条件分支等角度扩展了这一范式。标准在策略蒸馏通常让教师读取包含检索结果的完整轨迹，并直接以教师分布监督学生生成的 token。虽然检索信息已经进入教师上下文，它对后续预测产生的影响仍隐含在完整教师分布中，没有形成与该次检索观察对应的显式训练信号。换言之，现有方法能够从“教师如何评价学生动作”中学习，却没有专门利用“教师读取这段检索结果后，其评价发生了怎样的变化”。

本文研究如何将搜索过程中获得的中间检索信息直接转化为稠密的 token 级监督。我们的出发点很简单：如果一段检索结果确实影响了后续决策，那么教师能否直接访问该结果，应当改变其对后续 token 的预测。基于这一观察，我们提出**证据残差在策略蒸馏**（Evidence-Residual On-Policy Distillation，ER-OPD）。对于同一条学生生成的搜索轨迹，我们使用冻结教师进行两次独立前向计算。在证据可见视图中，教师可以访问完整检索结果；在证据隐藏视图中，我们仅阻断检索内容作为注意力键和值被后续位置访问，同时保持问题、学生生成历史、协议标签、token 序列和位置编码不变。两个视图之间的预测差异由此构成与中间检索观察直接相关的证据残差信号。

具体而言，设教师在证据可见和证据隐藏视图下的 logits 分别为 $$z_t^{\mathrm{obs}}$$ 和 $$z_t^{\mathrm{hid}}$$，我们首先计算证据残差：

$$
\Delta z_t^{\mathrm{ER}}
=
z_t^{\mathrm{obs}}-z_t^{\mathrm{hid}}.
$$

随后，ER-OPD 使用该残差增强证据可见视图下的教师预测：

$$
q_t^{\mathrm{ER}}
=
\operatorname{softmax}\!\left(
z_t^{\mathrm{obs}}+\Delta z_t^{\mathrm{ER}}
\right)
=
\operatorname{softmax}\!\left(
2z_t^{\mathrm{obs}}-z_t^{\mathrm{hid}}
\right).
$$

该构造把与检索结果直接可见性相关的预测变化转化为一个全词表蒸馏目标：当教师对某个 token 的预测在读取证据后发生明显变化时，该变化会直接进入学生的训练信号。我们在学生实际采样的 token 上计算反向 KL 优势，并将其与最终答案奖励产生的 GRPO 优势联合使用。检索内容本身仍被视为环境观察并从策略损失中屏蔽；证据残差只监督模型生成的推理、搜索动作和最终答案。因此，ER-OPD 不需要检索相关性标注或人工设计的过程奖励，就能在学生自身访问的轨迹上建立从“中间检索信息”到“后续生成决策”的稠密信用通道。

我们在 **[N 个开放域问答数据集]** 和 **[M 种模型规模]** 上验证 ER-OPD。与仅使用结果奖励的 Search-R1/GRPO 相比，ER-OPD 将平均 **[EM/F1]** 提升 **[X.X]** 个百分点；相较于直接蒸馏完整教师分布的标准 OPD，ER-OPD 提升 **[Y.Y]** 个百分点，并在 **[DGPO、SOD 或当前最强可复现基线]** 下保持优势。进一步实验从三个方面检验其作用机制：目标熵匹配实验用于区分证据残差与普通 logit sharpening，随机遮蔽和证据打乱实验用于排除额外教师计算带来的收益，按检索质量分层的分析则刻画 ER-OPD 在有效证据与噪声证据下的行为边界。实验结果 **[在完成多随机种子审计后填入一句最强、最可靠的结论]**。

本文的贡献如下：

1. 我们指出搜索智能体训练中的一个监督缺口：中间检索结果通常被用作策略上下文或检索轮次的标量奖励，但其直接可见性对应的后续预测变化尚未被显式转化为 token 级在策略蒸馏信号。
2. 我们提出 ER-OPD，通过同一学生轨迹上的证据可见与证据隐藏教师视图构造证据残差，并利用该残差形成面向后续生成决策的全词表蒸馏目标。
3. 我们通过与结果强化学习、标准 OPD 和教师指导方法的比较，以及目标熵匹配、遮蔽干预和检索质量分层实验，验证 ER-OPD 的有效性并分析其适用边界。
