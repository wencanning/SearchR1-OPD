# Figure 草图：从有用证据到有效监督

**状态：仅为用户审阅视觉效果的草图。所有数字均为人工设定的合成示意值，未进行相应实验；不能用于论文结果、引言事实陈述或方法性能比较。**

本版遵循 scientific-figure-making 的简洁坐标轴、无衬线字体、蓝/绿/红/灰配色、可编辑矢量导出与直接数字标注。英文用于图中；中文用于本设计说明。原有真实 CPU 实验图与数据完全分开保留。

## 选择：训练步数折线图—目标干预折线图—方法柱状图

(a) **How does the problem evolve?** 折线图：在自然的、证据充分的学生状态中，有多少状态属于“证据推动了正确方向，教师却仍偏错”？粗蓝线突出我们要解决的问题，绿色与灰色曲线分别给出已偏正确、没有有益更新的参照。横轴为 Student training step，诊断只来自 HotpotQA；教师保持冻结，改变的是各学生快照访问的状态。这里尚无这些步数的实测发生率。

(b) **Can the target cross the boundary?** 折线图：在上述目标状态中，固定学生前缀，从隐藏证据、开放证据到调整教师目标，正确候选的相对支持如何变化？50% 是两个候选支持相当的分界线；蓝线展示残差外推，红虚线展示只调温度、匹配目标熵的控制。折线连接的是计算条件，**不是训练步或时间序列**。

(c) **Does the student learn to correct?** 分组柱状图：同一份初始学生答错的 HotpotQA 留出问题，经过 OPD、完整可比 SOD、ER-OPD 训练后，有多少被纠正？分母对所有方法固定，不能让各方法按自己的错误重新选题。这里衡量学生实际生成，和 (b) 的教师候选支持是不同层次。

不选雷达图：当前需要证明的是一条逐层的证据链。不同指标的径向距离与面积不利于读出发生率、阈值和纠错幅度；三个常见坐标图能用明确刻度回答问题。

- (a) 各个训练步数的三类比例加和为 100%；示意检查点为 0/20/40/60/80/100/120。步数位置和比例均为布局占位，不代表实际已保存或已测量的检查点。
- (b) 18→36→68，以及温度对照 29，完全是假设值。不能引用为 ER 的测量结果。
- (c) 52/55/64 完全是假设值，没有新学生训练。
- 没有绘制误差带、显著性星号或样本量，因为这些会暗示并不存在的实证重复。
- 所有输出均保留全图合成数据标记，每个面板另有 SYNTHETIC 标记，文件名也含 SYNTHETIC。

## 将草图替换成论文实证图：实验安排

以下是待执行的安排，不是正在运行的任务。先确认这一版图的表达效果，再为整套统计启动模型计算；不为视觉草图打断现有训练。

### 第一阶段：为 (a) 收集独立状态

训练集仅为 HotpotQA。计划固定抽取 200 个未复核的 HotpotQA 诊断问题，在普通 OPD 参考运行预先固定间隔的学生快照上各生成一条自然轨迹；若选择 7 个快照，共最多 1400 个状态。同一组问题用于每个快照，控制题目组成差异；不按 EM 错误或 ER 分数筛选。检查点事先按固定步数间隔指定（例如每 20 个优化更新），不按最差验证点或最有利走势选择；实际间隔应结合真实训练计划与可用快照在打分前固定。教师保持同一冻结版本；不把不同训练方法的轨迹混成训练阶段。若快照不可得，先记录设计修订再打分。

先对原问题、检索材料和答案做隐藏方法分数的语义审查。记录证据充分、证据不足、参考歧义和技术排除，不把排除者塞进图中任何一段。主图分母为证据充分且技术合格的状态，报告实际样本数与来源；200 个问题 × 检查点数是计划规模，不是目前图的 n。每个检查点分别报告有效状态数和排除数量；总体区间按问题聚类重采样，因为不同检查点重复使用同一组问题。另报所有检查点均合格的共同子集作为敏感性分析，避免证据充分性的样本筛选变化被误读成阶段效应。

在教师评分前固定正确答案和实际错误答案的别名集合。两边使用同一套完整终止格式，通过 log-sum-exp 聚合各自合法字符串的概率质量。别名、候选长度和答案关闭格式都做敏感性分析。候选池来自先冻结的学生、普通教师与隐藏证据教师输出，不能根据 ER 最有利的竞争答案修改。

令完整正确/错误候选的对数概率差为 M。按以下互斥顺序分类：

1. Already correct：M_visible > 0；名称只指这组候选排序正确，不能直接当自由生成正确。
2. Helps, still wrong：M_hidden < M_visible ≤ 0。
3. No helpful update：其余仍偏错状态，包含无变化和恶化。

主图使用完整答案 M；局部首个不同 token 的旧 m 诊断单独报告。接近零的值另做预先指定容差敏感性；若要增加“近似持平”第四类，必须在打分前固定。按问题重采样给出区间，不能把 token 当独立样本。比例太小或区间很宽时，缩小论文主张，不继续挖案例直到图变好看。

### 第二阶段：为 (b) 做固定状态目标比较

使用 (a) 中由原教师定义的 Helps, still wrong 子集，不依据 ER 能否翻转选取。所有教师条件固定模型、精度、词表、前缀和候选；复核失败单列，不混入主分析。

图中的相对支持定义为 sigmoid(M)=P(correct set)/(P(correct set)+P(competing wrong set))。这只是限定候选集合中的相对支持，**不是模型生成正确答案的总体概率**。图上显示该子集的平均值和按问题配对 bootstrap 区间；均值越过 50% 也不能证明每个状态都已纠正，因此另报逐状态排序翻转率和开放生成的净纠错率。

计算原教师的隐藏/可见分布，ER alpha=1 目标，以及逐位置熵匹配的温度控制。alpha=.5/1.5 只做预定敏感性，不用最佳值替代主结果。随机等长度屏蔽与无关/冲突证据属于必要边界控制，可放补充图。

若 ER 只在局部 token 上有改善、完整答案或自由生成不改善，就不能将 (b) 标为方法完成纠错。实测若没有蓝线跨越分界线，应画真实结果并调整叙事。

### 第三阶段：为 (c) 验证学生训练收益

从未参与训练的 HotpotQA 留出问题中，用共同的初始学生和冻结教师定义探针集：初始学生确实答错，且固定教师属于 Helps, still wrong。样本名单对三个训练方法保持完全一致，不使用训练后各模型自己的错误集合重新筛选。

比较 OPD、完整可比 SOD 和 ER-OPD，在相同数据/rollout/更新预算下训练，至少三次独立训练重复；另报告教师计算量与墙钟预算的比较。SOD 配置不能用本地无 GRPO 的单 rollout 消融替代原方法完整比较。固定解码设置和答案评分，报告每个 seed 的结果与问题配对统计；区分跨训练种子变异和跨问题不确定性。

图 (c) 显示这份固定初始错误集的纠错率。补充报告初始正确集的保持率、整体测试集 EM/F1 和搜索成本，避免只对有利子集报告收益。可追加 SOD+ER 验证重加权和目标调整是否互补。

若不跑新学生训练，(c) 必须改名为教师目标下的自由生成结果，并移除 SOD 学生方法比较；不能沿用当前图名填入教师分数。

## 对引言的作用

(a) 建立真实问题及规模 → (b) 检验证据残差是否提供有效目标干预 → (c) 证明目标改善能够转化为学习收益。现阶段这只是拟议的论证结构，不能把这些合成数字或预期结果写进引言。

在所有实验完成前，可以表述研究问题及方法动机；“我们发现普遍存在”“显著提升”“有效解决”等结论必须等实测和审计。现有小样本真实结果仍以 reports/er_correction_cpu_20260914/REPORT.md 为准，不能被此草图覆盖。

## 训练步数版本的解释边界

这版更接近 SOD 的训练动态展示，但不能先要求蓝线持续上升。若比例持平，支持“问题持续存在”；若下降，说明问题随训练减轻；只有真实上升且不确定性允许时，才能讨论恶化。当前曲线全部合成，因此不支持其中任何一种实证结论。真实数据点用折线直接连接，不做制造趋势的平滑。

置信带应来自真实重复训练或按问题聚类的重采样，两者含义分开说明；当前没有绘制置信带。阶段间证据充分率及格式失败率需另外保留，尤其不能只画剩下的成功完成轨迹而隐去后期未终止状态。
